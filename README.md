# 2026 토목체전 참가자 안내

2026년 9월 12일(토) 서울대학교 종합운동장에서 열리는 토목체전의 참가자 안내
페이지입니다. QR로 접속하면 리플렛 4면을 옆으로 넘겨보고, 게임설명 면에서
게임을 누르면 그 게임의 룰 카드가 열립니다.

주관 · 대한토목학회 대학생위원회 대외협력본부

## 파일 구조

```
index.html          페이지 본체. 수정은 여기서
assets/             Swiper 11 (MIT) — 건드릴 일 없음
images/panel-1..4   리플렛 4면 (표지·배치도 / 타임테이블 / 게임설명 / 경품)
images/rule-1..6    게임 룰 카드 6장
```

## 이미지 교체

`images/` 안의 파일을 **같은 이름으로 덮어쓰면** 끝입니다. 코드는 건드리지
않아도 됩니다.

권장 규격
- 리플렛 4면: 세로형, 가로 **1000px 이상**, JPG
- 룰 카드 6장: 세로형, 가로 **1080px**, JPG

## 게임 순서

게임설명 면의 위에서부터 `rule-1` → `rule-6` 순서입니다.

| | 게임 | 룰 이미지 |
|---|---|---|
| 1 | 구루마 컬링 | `images/rule-1.jpg` |
| 2 | 토목철인 3종 | `images/rule-2.jpg` |
| 3 | 구속 측정소 | `images/rule-3.jpg` |
| 4 | 탄성한계 측정실험 | `images/rule-4.jpg` |
| 5 | 홀인원 토공사 | `images/rule-5.jpg` |
| 6 | 인간 항타기 | `images/rule-6.jpg` |

## 터치 영역 조정

리플렛 디자인이 바뀌어 게임 줄 위치가 달라지면, `index.html` 안의 `GAMES`
배열에서 각 게임의 `top` / `bottom` 값(면 높이에 대한 %)만 고치면 됩니다.
